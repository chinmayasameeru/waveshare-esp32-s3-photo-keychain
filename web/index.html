Waveshare Photo Display

Select the image you want stored on the board. The browser converts it to a 320×240 JPEG and flashes it together with the firmware. The ESP32 itself uses no Wi-Fi.

Choose an image to enable flashing.
USB

Use desktop Chrome or Edge over HTTPS with the ESP32-S3 connected by USB. After flashing, unplug/replug the board; it will show the selected image automatically.
